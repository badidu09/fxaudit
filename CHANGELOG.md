# Changelog

## 0.1.0 (unreleased)

First version.

- Lua 5.4 and CfxLua parser reporting every syntax error of a file.
- Cross-file resolution of globals, per resource and per side.
- Rules for variables, logic, security, performance, leaks, manifests and events.
- Console, JSON and SARIF reports, with a score per resource.
- Inline suppressions and a `.fxaudit.lua` configuration read without being executed.
